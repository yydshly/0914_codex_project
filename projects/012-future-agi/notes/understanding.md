# 我们对 Future AGI 的理解

## 核心能力

**检测和评估 AI 的能力与表现，具体落在 AI 应用的业务任务上。** 这里的应用包括模型、提示词、知识检索和工具。平台通过执行记录和业务标准，检查回答是否正确、有依据、符合要求，工具是否用对，任务是否完成，同时观察速度、成本与稳定性。

记录提供检测证据；评测给出判断；诊断帮助找到问题；版本实验帮助验证改进。它不是仅仅保存聊天记录，也不是一次测试就能给出 AI 的通用能力结论。

## 检测方式

| 方式 | 检测思路 |
| --- | --- |
| 规则与函数 | 按明确条件检查格式、字段、数值等 |
| 参考答案与标注比较 | 比较回答差异、检索命中和排名 |
| 向量相似度 | 把文本转换为向量，衡量语义接近程度 |
| 模型裁判 | 把回答、资料与标准交给评测模型判断 |
| Agent 调查 | 通过多轮分析和工具查询补充证据，再评测；本轮依据产品文档 |
| 工具调用匹配 | 对照预期工具名称和参数检查调用 |
| 执行轨迹匹配 | 对照预期流程检查步骤、顺序和遗漏 |

正确性、安全性、语气等是“检测角度”，上述方法是“检测手段”。同一个角度可以组合多种方法；语义相似与调用匹配都不能单独证明业务结果正确。七项是研究归纳，并非官方七种评测引擎。

## 当前研究阶段

已完成官方文档、固定版本关键源码和初步流程的整理，形成网页与总览图。**根本原理需要后期深入研究，实际检测效果尚未实测。** 当前材料说明观察到的能力与实现思路，不宣称已经完整解释所有算法或证明检测可靠性。

后续重点：

1. 跟踪数据进入每种评测器、形成判分并返回解释的完整路径，核对模板、公式、阈值和失败处理。
2. 研究模型裁判为什么作出某种判断，如何用人工样本校准，以及误判、波动和评测数据偏差。
3. 深入核对错误定位、聚类与优化算法的内部实现，区分诊断推测、相似分组和因果依据。
4. 用最小业务测试集实测准确性、重复稳定性、延迟和成本，比较不同方法及组合方案。
