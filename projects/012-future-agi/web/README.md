# Future AGI 中文研究网页

围绕“记录过程 → 检查质量 → 沉淀案例 → 改进提示词 → 重新验证”解释能力与原理。

## 页面内容

- 七项能力：运行追踪、自动评测、对话模拟、数据集与实验、提示词优化、模型网关、在线防护。
- 执行树与架构图：区分模型请求路径和追踪事件路径。
- 三种评测方式切换：代码计算、模型裁判、Agent 调查。
- 七类分析手段详解：规则、参考比较、向量相似度、模型裁判、Agent 调查、工具调用匹配与轨迹匹配。
- 技术原理总览图：汇总证据输入、采集存储、评测、诊断、优化与验收，支持高清 PNG 与 SVG 下载。
- 区分组合评分、错误定位、已有失败聚类与 Error Feed 主动扫描。
- 提示词优化工作流与六种算法简述。
- 客服、知识库问答、版本升级三个使用场景切换。
- 开源与企业范围、功能依赖、来源和研究笔记下载。

所有示例为教学内容，未连接真实模型或平台服务。没有表单、账号收集、分析统计或外部脚本；核心内容与样式支持离线使用。关闭 JavaScript 后三个评测方式和三个场景全部保留可读，能力介绍使用原生展开控件。

## 打开网页

在总仓库根目录运行：

```powershell
python projects/012-future-agi/src/build_site.py
python -m http.server 8098 --bind 127.0.0.1 --directory projects/012-future-agi/web/dist
```

打开 [本地网页](http://127.0.0.1:8098/)，也可直接打开构建后的 `dist/index.html`。本地服务关闭后可使用文件方式，或按上述步骤重新启动。

HTML、CSS、JavaScript 与图标直接维护于本目录，无前端依赖。构建复制到 `web/dist/` 并校验资源、锚点及控件引用；产物被版本控制忽略。资源使用相对路径，支持未来在统一 GitHub Pages 子目录发布。

总览图由 `src/draw_overview.py` 生成到 `assets/`，需要 Pillow 与指定的中文字体。更新图中文字后，先运行绘图器再构建网页；网页构建本身无需 Pillow。分析说明与证据集中在 `notes/analysis-methods.md`。
