# 技术原理总览图

- `future-agi-technical-overview.png`：2400 × 4310 高清图。
- `future-agi-technical-overview.svg`：保留文字和图形的可缩放版本，建议安装微软雅黑或 Noto Sans CJK SC。
- `future-agi-technical-overview-preview.png`：1200 × 2155 网页预览。

图示汇总输入、采集存储、七类评测手段、错误诊断、优化实验、场景与边界。为本项目原创研究归纳，不是上游界面截图，也不是运行结果。依据见 `notes/analysis-methods.md` 和 `notes/sources.md`。

在仓库根目录运行 `python projects/012-future-agi/src/draw_overview.py` 可重绘；需要 Pillow 与脚本指定的 Windows 中文字体。绘图器检查文字宽度与段落边界，交付前已查看预览核对布局。
