接口依据 ↗

API / MCP

API 供程序按参数请求数据；MCP 让 AI 发现和调用工具，常把 API 包装起来。MCP 不是另一份原始数据，API 存在也不保证对应 MCP 工具已上线。

RSS / Atom / Webhook

RSS、Atom 用于订阅更新；Webhook 由来源向回调地址推送事件。适合跟踪新增内容，不能默认拿到完整评论、全文或历史全量。

网页抓取 / 正文提取

Firecrawl、Jina Reader 等接受 URL，返回正文或 Markdown；Bright Data 的所列路径返回 HTML。我们仍可通过 API 调用它们，这是不同层面的“获取方式”。

数据集 / SDK / 浏览器扩展

数据集交付批量文件；SDK 是调用封装，扩展是操作界面。后两者通常仍依赖服务密钥和接口，不会自动增加数据覆盖或权限。
