# 能力、产出与实际意义

“已有实现”表示找到代码；“作者披露”表示上游说明；本项目未实测抖音在线采集。

**核心价值是“如何获取并整理抖音信息”的工程基础：会话与接口负责访问，分页与队列负责批量执行，媒体与结构化文件负责落地。** 这些产出可供素材库、内容研究和另行接入的 AI 分析使用；不把已有模块当成当前稳定采集的保证。

| 能力 | 原理与设计产出 | 边界 |
| --- | --- | --- |
| 视频、图集、音乐 | 详情、选源、传输 → 媒体及附加资源 | 多项详情接口受限；无水印和画质依赖来源 |
| 主页、合集、喜欢、收藏 | 分页枚举 → 按作品下载 | 收藏限当前账号；多项端点受限，主页可尝试浏览器兜底 |
| 搜索 | 网页搜索、游标、去重 → JSONL | 不自动下载结果，也不保证全量 |
| 热榜 | 热搜列表 → 带时间的快照 | 无内建长期趋势分析 |
| 评论 | 评论分页与去重 → JSON | 回复仅第一页；不做情绪、主题和用户分析 |
| 直播录制 | 获取流并分块保存 → FLV 等 | 实验性；作者说明 HLS 路径只保存播放列表 |
| 直播回放 | 获取回放资料、选源与下载 | 有模块及入口，未验证当前可用性 |
| 主流程语音转写 | 提取音轨、调用服务 → TXT／JSON | 需配置；识别语音不等于理解画面 |
| 独立 Whisper 脚本 | 单文件或目录本地识别 → TXT／可选 SRT | 需要模型与依赖；与主流程的输出选项不同 |
| 下载管理 | asyncio 并发、限速、重试、回退 | thread 主要控制异步并发；重试不解决确定性拒绝 |
| 归档与增量 | 文件检查、元数据、清单、SQLite 历史 | 跳过行为受配置影响，不能一概称为纯磁盘或双重去重 |
| HTTP 服务 | FastAPI 提交任务及查询 | 任务内存保存、重启丢失；当前服务下载不启用历史数据库 |
| 通知与部署 | Bark／Telegram／Webhook、Docker | 需配置；长期定时运行须另接调度 |

## 三种产品形态

- **CLI：**配置链接、目录、模式、数量、可选功能后运行 Python。
- **HTTP 服务：**供自己的应用提交下载任务，不是完整 SaaS 或分析平台。
- **Douzy 桌面版：**另行发布，作者列出抖音、TikTok、YouTube 工作台。关键桥接不在公开库。Desktop 0.11.5 说明称单链接入口无需邀请码，批量和高级流程仍涉及内测资格。

## 效果与价值

本次“效果”是设计输出结构，不是未做过的成功案例。网页中的作品名、文件名和步骤是解释示例；图片是研究示意图，不是产品截图。

1. **素材归档：**文件和元数据保存到本地，减少手工整理。
2. **内容研究：**搜索、热榜、评论及转写给后续分析提供材料。
3. **二次开发：**复用解析、分页、传输、队列和存储。
4. **架构学习：**分清网页会话、业务接口、媒体 CDN 和对外服务，理解登录不保证请求成功。

可扩展为“发现 → 筛选 → 下载和评论 → 转写 → AI 分析 → 知识库”。AI 分析、长期调度与收益评估需另接系统，上游可用性必须先验证。

## 作者现状披露

2026-08 起喜欢、收藏受限；09-10 起合集作品受限；09-14 起详情、主页和多个合集及音乐端点受限。作者称用户资料、关注、评论、直播间、热榜和搜索部分端点仍可直连。这些是作者特定时间的观察，不是本次逐项实测。

主页浏览器兜底存在，但作者称尚未验证新门禁。桌面桥接宣称可处理限制，本研究未独立验证。源码中的模拟测试即使通过，也不能证明真实端点可用；本次没有运行上游测试。
