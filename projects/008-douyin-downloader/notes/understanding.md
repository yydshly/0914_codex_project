# 我们如何理解它：账号、浏览器、接口与服务器

研究基准：2026-09-16，commit `125ddf4d7196b7a18fe3a0258cc746503c9d1c57`。这是源码解释，不是在线可用性报告。

## 定位与参与者

我们最终的定位是：**抖音信息的获取与整理层**。它把获取信息、批量处理、下载媒体与保存记录组织成可重复执行的工程流程。后续的业务分析、总结、洞察与知识库是另一层，不能混同为本库已经提供的完整产品。

这是复用抖音网页内部接口的内容采集与下载工具。Python 版主要直接请求接口；浏览器用于登录和特定采集路径；Douzy 桌面版还有独立的网页请求桥接。“登录”“API”“爬虫”分别回答：以谁的身份、通过什么入口、是否由程序自动采集。

| 参与者 | 作用 |
| --- | --- |
| 用户与账号 A | 输入任务、完成登录；A 是访问身份，账号本身不会发请求 |
| 浏览器 | 承载会话、网页 JavaScript 和平台 SDK |
| Python 程序 | 构造请求、分页、去重、选源、下载和保存 |
| 抖音业务服务器 | 校验请求，返回搜索、作品、评论等数据 |
| 媒体服务器 / CDN | 返回视频、图片、音频或流数据 |

服务器按职责拆分仅用于理解，不代表官方部署拓扑。博主 B 是查询目标。A 查看 B 的公开作品不需要 B 的密码，内容来自平台服务器而不是 B 的手机。A 的身份不自动打开私有内容；收藏模式限定为当前 Cookie 对应账号。

## 登录如何衔接请求

1. `tools/cookie_fetcher.py` 用 Playwright 打开抖音网页，用户完成登录并确认。
2. 工具读取浏览器 Cookie，筛选并保存到本地 JSON；可更新 YAML 配置。
3. `CookieManager` 加载这些信息，`DouyinAPIClient` 用于网络会话。
4. 请求还带有浏览器参数、请求头和签名；Cookie 不是全部校验条件。

Cookie 是一组信息，部分关联账号会话，部分用于访客或风控。存在 Cookie 不等于已登录；已登录不等于每个接口都会接受请求。是否需要登录取决于端点、内容和平台策略。本研究网页没有读取 Cookie 或登录账号的入口。

## 三种网络路径

### A：公开版接口直连

浏览器登录 → 读取会话信息 → Python 构造请求 → 抖音业务接口 → 结构化结果 → Python 翻页、保存或下载。

客户端使用 aiohttp 会话，构造浏览器参数与 token，优先尝试 a_bogus 签名，相关实现不可用或失败时可退回 X-Bogus。平台仍可拒绝请求。这条路径不要求每次打开网页点击按钮。

### B：公开版主页浏览器兜底

Python 启动 Playwright → 打开作者主页 → 滚动 → 网页请求作品列表 → 程序监听响应并提取数据 → Python 处理。

程序也可从页面链接等位置提取作品 ID。有完整作品资料时直接复用，否则可能再请求详情。兜底以主页 post 模式为主，不能推广成所有功能都走浏览器。该上下文对 Cookie 有自己的处理规则，也不能理解为完整复制当前桌面浏览器的全部状态。

### C：Douzy 桌面版页面桥接

Python 提交请求意图 → 内置抖音页面发请求 → 网页 SDK 补齐环境校验 → 结果交回 Python。

共享客户端接受 `page_bridge` 参数。公开 CLI 没有注入桥接，仍走直连。作者说明桌面版由 Electron 登录窗口代发特定请求；关键 `core/page_bridge.py` 不在公开库中。本次没有安装桌面版或验证其成功率。

## 搜索、评论、下载

**搜索：**关键词和分页参数 → `/aweme/v1/web/general/search/single/` → 从 `data[].aweme_info` 提取作品 → 游标翻页 → ID 去重 → JSONL。抖音决定匹配排序，本库没有全量搜索索引。底层有排序、时间参数，命令行只暴露部分选项。

**评论：**作品 ID → `/aweme/v1/web/comment/list/` → 一级评论分页与去重 → JSON。开启回复时按评论 ID 额外请求 `/aweme/v1/web/comment/list/reply/`，当前自动流程仅取第一页。现成入口主要挂在下载工作流上；独立 helper 不是独立 HTTP 路由。

**下载：**短链跳转 → 作品 ID → 详情 → 选媒体地址 → 请求媒体服务器 → 临时文件 → 可用时校验长度 → 正式文件与记录。批量下载先枚举作品。无水印是优选来源，不是画面修复；最高画质不保证上传原文件。

## 两层 API

你的应用 → 本库 FastAPI → Python 后端 → 抖音网页内部接口。

左侧由你部署，提供下载任务服务；右侧供抖音网页使用，不因本库封装就成为承诺稳定的第三方开放 API。公开服务没有把搜索、评论等全部封装成路由。

## 为什么登录成功仍可能失败

平台既判断会话身份，也判断请求环境和行为。作者披露 Argus 对多个非页面请求返回 403；复制 Cookie 或重试不一定补得上网页动态校验信息。浏览器路线利用真实页面环境，不会赋予更多账号权限。

本项目确认的是代码和作者说明，不能把作者声明变成实测结论。采集完整性、接口成功率、桌面效果和长期稳定性仍需独立验证。见 [固定版本来源](sources.md)。
