# 全景图制作记录

- 最终文件：`assets/douyin-overview.png` 与 `assets/douyin-overview.svg`。
- 尺寸：2400 × 2640。中文标注和连接关系由固定文本与布局生成。
- 可复现源：`src/draw_overview.py`；需要 Pillow 与 Windows 微软雅黑字体。网页构建直接使用已保存图片，不需要图片生成依赖。
- 绘图内容：产品形态；账号、浏览器、Python、业务服务器与媒体服务器的关系；六类能力；输出价值；当前边界。
- 图片是研究示意图，不是上游应用截图，不包含真实采集数据或成功率。

## 制作方式

首先尝试一次内置 imagegen，服务返回网络错误，没有产生图片。未切换 API／CLI 模型，也未提供密钥。随后改用适合精确流程图的确定性绘图，输出高清 PNG 和可编辑 SVG。

最初生成提示词的内容摘要：中文横向技术信息图，标题“抖音内容采集：能力、原理与边界”，浅底、深蓝文字、青色请求路径与珊瑚色边界；区分公开 Python 版与独立 Douzy 桌面版；从账号 A 的浏览器登录到 Cookie、Python、业务接口与媒体传输；强调账号 A 与博主 B 的区别；六类能力、归档／研究／开发价值与当前风控限制；不得编造截图、成功率或在线实测。

最终图片采用源码中的完整标注文案，生成式提示词未作为最终成图来源。后续修改应优先编辑绘图源并重新导出。
