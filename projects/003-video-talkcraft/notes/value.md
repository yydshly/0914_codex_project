# 价值与适用边界

以下为基于 [源码与实验](architecture.md) 的研究判断，不把作者单样本的速度数据视为普遍承诺。

## 核心价值

1. **共享时间轴**：字幕、动效和音效绑定稿件中的词，减少分别调整造成的相对错位。共同参考错误时，多个模块也可能一起错。
2. **复用制作经验**：配方将意图、输入类型、参数、代码和反例放在一起。复用运动结构后调整内容，比每次凭效果名称重新生成更易复现。
3. **降低局部修改成本**：按镜头缓存有利于反复改数字、素材和排版；公共配置和镜头交叠仍可能扩大重渲范围。
4. **可追溯工程**：来源、分镜、时间表、选卡和检查结果均有文件，便于接手、改稿和系列内容维护。

## 适合什么需求

| 场景 | 判断 | 原因 |
| --- | --- | --- |
| 中文科普、产品说明、观点口播 | 适合 | 声音为主线，画面解释和强调 |
| 多期统一风格栏目 | 值得验证 | 配方和主题可重复使用 |
| 同步人物的技术讲解 | 适合合成侧 | 人物角标、截图和字幕可以协调 |
| 临时剪一小段日常录像 | 未必划算 | 配置与流程成本可能高于手动剪辑 |
| 生成真人讲话或电影场景 | 需要外部工具 | 没有 TTS、数字人或实拍场景生成模型 |
| 任意 MP4 还原编辑图层 | 不适合 | 需要原始工程契约 |

## 不能省掉的成本

- Agent 理解、编码、调试、审片的时间与调用成本。
- 真实素材质量、收集，以及人物录制或外部数字人生成。
- 首次语音模型和浏览器配置、渲染资源。
- 换文案、画幅、背景和人脸位置后的布局检查。
- 对英文品牌、数字读法、重说和停顿的听核。
- 工具本身非商业许可与第三方素材、音效及 Remotion 的使用条件。作者声明商业使用需先授权。

## 总结

新增的 [完整制作模型](production-model.md) 将复用价值扩展到三层一致性、语义正确性、选卡优先级、时间容量、素材条件、职责、修改影响、失败回退和交付成本。其实际价值是让每次选卡有理由、每次修改知道需要重查哪里、每次验收知道检查覆盖了什么。

技术正确、表达正确和观看有效需要分别评估。上游提供部分执行机制与制作规范，本研究给出更完整的组织方式；这些建议尚未通过完整口播生产实验验证。

它的价值来自“配方库 + 时间契约 + 可重渲工程 + 验收流程”的组合。单有配方容易变成模板堆叠，单有代码生成不易保持效果，单有机器检查也不能证明内容有效。

对本研究仓库最值得迁移的三项设计是：共享声音时间表；效果与输入条件、反例一起保存；明确每项检查的覆盖范围。是否投入真实生产，下一步应以自有配音的小样验证，而不只看画廊效果。
