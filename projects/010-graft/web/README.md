# Graft 中文交互导读

独立研究网页，延续总仓库的原生 HTML / CSS / JavaScript 与静态打包方式。无需前端依赖，可离线阅读；外部来源链接需要联网。

## 内容

- 三个预设任务：调查登录掉线、修改 Token 接口、理解登录流程。
- 文件与依赖图联动，点击模块查看说明及代码。
- 接口轮廓、相关片段、完整示例三种阅读深度；按实际示例计算展示行数。
- 六步技术流程：源码、语法解析、关系解析、检索排序、上下文组织、助手使用。
- 未变化、代码变化、刷新失败三种更新状态。
- Graft 与 Caveman 对照、六项 MCP 能力、证据边界与源码链接。

示例使用预设选择，不实现上游检索、解析、图排序或模型调用。示例行数不代表 Token 或真实节省率；代码用于教学，不是可部署的认证系统。

## 本地运行

在总仓库根目录执行：

```powershell
python projects/010-graft/src/build_site.py
python -m http.server 8096 --bind 127.0.0.1 --directory projects/010-graft/web/dist
```

打开 http://127.0.0.1:8096/，也可以直接打开 dist/index.html。

构建产物位于 web/dist（被版本控制忽略），已按总仓库的子路径部署方式使用相对资源。当前仅本地预览，未发布到公共站点。
