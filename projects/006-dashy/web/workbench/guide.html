三分钟体验我的数字工作台

这是本地中文演示的在线版本，无需安装或接入码。

  1. 找应用：在搜索框输入“代码”，观察 GitHub 卡片被筛选出来，清空恢复。
  2. 换风格：从主题菜单选择一种配色，或切换布局、卡片大小。
  3. 改卡片：打开“选项”，进入编辑模式，修改卡片标题或添加入口，选择“保存到本地”。修改只保存在当前浏览器中。
  4. 看组件：北京时间实时更新；数据组件读取一份明确标注的固定示例 JSON。
  5. 体验嵌入：点击“可切换的服务示例”打开弹窗，或“体验嵌入工作区”打开完整工作区，在里面切换模拟状态。
线上版不提供服务器写盘、真实服务探测或本机内存读取。需要这些能力时，可运行仓库中的本地演示。在线编辑不会修改公共页面的默认配置。
