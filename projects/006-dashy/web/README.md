# 我的数字工作台与研究网页

研究页保留架构总览和本机实拍，并在首屏提供独立体验入口，在页面中直接嵌入可操作的中文工作台。

在研究仓库根目录构建：

```powershell
python projects/006-dashy/src/build_workbench.py
python projects/006-dashy/src/build_site.py
```

首次构建需要 Node 24、Yarn 1.22.22 和联网。前者下载固定版本的上游源码并生成独立静态构建，后者把研究内容与工作台一起打包到 `web/dist/`。线上路径为 `/006-dashy/workbench/`，使用 hash 路由。

`workbench/` 中保存公开中文配置、在线指南、模拟面板和固定 JSON 数据。在线支持搜索、主题/布局切换、卡片编辑并保存到当前浏览器、时钟、数据组件、弹窗与嵌入工作区。服务器写盘、真实服务探测和本机信息继续由本地完整版提供。

公开构建不引用 `127.0.0.1`，不发布 Node 后端、日志、依赖或本地缓存。编译适配仅处理部署路径、存储命名空间和 Service Worker；工作台界面沿用本地演示使用的 Dashy 版本。
