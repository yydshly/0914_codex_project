# Dashy 研究展示网页

静态研究页使用架构总览图和原版工作台截图引导阅读，整理能力、价值、实现流程、NAS 示例、网页与桌面应用边界、验证范围及本机复现方法。

构建（在研究仓库根目录运行）：

```powershell
python projects/006-dashy/src/build_site.py
```

输出为本目录的 `dist/`，由仓库统一的 GitHub Pages 工作流打包到 `/006-dashy/`。

发布内容采用明确清单：HTML、CSS、图片预览脚本、5 个图像资产，以及无密钥的示例配置。不会复制 `.cache/`、本机 Node 进程、日志或原版后端。公开页仅展示截图；其中的本机内存与时间为历史实拍，不会发起本机 API 请求。

完整原版演示通过上一级的 `start.ps1` 在本机运行。用户需要的状态探测、代理和配置写盘由本机后端提供；这些能力不由 GitHub Pages 静态网页执行。
