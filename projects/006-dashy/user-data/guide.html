006 / DASHY 原版演示

一个网页，装下你的日常入口。

现在运行的就是 Dashy 原版。我们只准备了中文配置和本地示例服务，你可以直接修改、搜索和切换视图。

进入工作台 →

① 找应用：在搜索框输入「代码」

卡片会按名称、说明或标签过滤。清空搜索恢复全部入口。点击 GitHub、Notion 等卡片会打开对应网站；这些入口不会替你创建账号或登录。

② 看信息：观察时钟和刷新时间

时钟实时跳动；本机信息每 10 秒刷新，显示这台电脑的内存和演示进程运行时长。这体现了 Dashy 通过 API 把数据放在首页的能力。

③ 看状态：让服务从维护中恢复

点击「可切换的服务示例」，在弹窗中按按钮切换状态，关闭弹窗后等约 10 秒。Dashy 的状态灯会随真实 HTTP 响应变化。这里的服务是专门准备的本地示例。

④ 改成自己的：切主题、编辑卡片

使用顶部主题菜单更换外观；在“选项”中进入编辑模式，修改卡片标题或添加自己的网址。保存到本地只影响当前浏览器；保存到磁盘会修改本演示的配置文件。

⑤ 一个页面内工作：点击「体验嵌入工作区」

示例控制面板会嵌入工作区。其他网站能否嵌入取决于它们的安全策略；普通链接仍可用新标签页打开。

它解决的问题：入口太分散、网址难记、要打开多个页面才能看概况。
天气、NAS、Pi-hole、Nextcloud 等也有组件，需要接入你自己的服务地址或 API 密钥。本演示不依赖这些账号。
