# 来源与复现边界

- 上游：[Lissy93/dashy](https://github.com/Lissy93/dashy)
- 固定 commit：`6c56436d5f044d3c53371891c9d9a8c8df8c4606`
- package.json 版本：`4.6.14`
- 许可证：MIT，见 [原始许可证](UPSTREAM-LICENSE.txt)
- 研究日期：2026-09-16
- 本地运行环境：Node 24.19.0 / Yarn 1.22.22，分别保存在子项目 `.cache/runtime`、`.cache/tools`。本次 Node 来自本机已有的运行时副本；首次联网复现使用同版本 npm 包。

运行的是上游 Vue / Express 应用，没有重写 Dashy 的界面或核心能力。上游源码通过固定 commit 压缩包获取，保存在忽略目录 `.cache/source`，使用上游 yarn.lock 安装。

研究增加的文件：中文 YAML 配置、体验指南、控制面板、启动/停止脚本，以及 `src/server.cjs` 中的本地演示接口。后者在原版 Express 应用前增加 `/demo-api/*`，为原版组件提供容易验证的数据。

数据边界：时钟是真实时钟；内存为本机 os.freemem / os.totalmem 的实时读数；运行时长和请求计数来自演示进程。正常/维护中接口是明确标记的示例，返回实际 HTTP 200 / 503，用来验证原版状态检查。常用工具卡片只是入口，不会登录或操控第三方账号。当前没有接入天气、NAS 或企业系统密钥。

完整原版演示服务只监听 `127.0.0.1:8060`。GitHub Pages 同时发布研究页与本地中文工作台的静态在线版本，支持搜索、换主题、编辑并保存到浏览器、组件和工作区。公开配置将本机内存替换为注明来源的固定示例 JSON，服务切换面板改为浏览器模拟，不执行服务端探测或写盘。浏览器存储键加上 `dashy006:` 前缀；在线构建不注册或清理 Service Worker。构建产物包含上游 MIT 许可证，不包含本地后端、依赖和日志。
