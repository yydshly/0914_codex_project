# 架构与原理

这是固定版本仓库的逻辑分解，不是生产后台部署架构，也不是核心混淆代码的逐行还原。模块角色用公开文档、可读测试、目录和动态结果相互印证。

## 主流程

| 阶段 | 处理与产出 | 对应位置 |
| --- | --- | --- |
| 收集与识别 | 读取日志和需求，归纳问题信号 | `src/evolve/pipeline/collect.js`、`signals.js`、`src/gep/signals.js` |
| 搜索与选择 | 选择策略、候选案例，记录决策 | `src/gep/selector.js`、`test/selector.test.js` |
| 形成执行请求 | 组合步骤、约束、上下文与验证要求，生成提示词 | `src/gep/prompt.js`、`test/prompt.test.js` |
| 分发 | 输出提示或进入宿主集成路径 | `src/evolve/pipeline/dispatch.js`、`test/evolveDispatch.test.js` |
| 真正执行 | 模型使用文件和命令工具修改、测试 | 宿主／执行适配路径；本次未运行 |
| 固化与反馈 | 检查结果与变更范围，记录资产与事件 | `src/gep/solidify.js`、`assetStore.js`、`memoryGraph.js` |
| 可选联网 | 查询、发布、同步、网络任务 | `src/gep/a2aProtocol.js`、`src/proxy/` 等，未做端到端验证 |

固定版本链接见 [来源表](sources.md)。仓库还包含 `src/solo/` 等执行路径，需要单独研究；基础模式输出提示词不是所有 CLI 功能的完整描述。

## 三种经验角色

- **Gene 是方法。** 包含触发信号、适用条件、步骤、限制和验证命令。随包修复 Gene 包括提取信号、估算影响范围、最小修改、验证及记录。
- **Capsule 是案例。** 对应某次执行的方法、触发条件、摘要、结果和环境等，具体字段随协议版本演进。
- **EvolutionEvent 是过程。** 把一次迭代的选择、变化和结果串起来，用于追踪与后续决策。

“继承”意味着取得材料并在任务中使用，仍依赖当前模型与工具。跨框架项目不会因为旧案例标记成功就自动兼容。

## 选择不等于全面理解业务

选择器的 47 项测试覆盖信号、多语言、历史偏好、禁用、随机探索和环境相关抑制。它们验证具体规则，没有证明选择器能判断任意方案的全部业务适用条件。

上游 `test/selector.test.js:425` 明确测试蒸馏 Gene 的兜底。本次对完整种子库输入 `zz_unrelated_74392` 返回 env-vars Gene，模式 `distilled_fallback`。这是有意设计，不应被记为真实命中。

## 哈希、格式与正确性的区别

SDK 的 `canonicalize` 排序并序列化字段；`computeAssetId` 默认排除自身 ID，计算 SHA-256；`verifyAssetId` 比较重算结果与声明标识。

需要分开四种问题：

1. 格式校验：字段和类型是否合规。
2. 内容哈希：内容是否与标识一致。
3. 执行验收：运行后是否满足任务要求。
4. 跨环境复用：换个项目是否仍然有效。

探针对含 `2 + 2 = 5` 的合成策略计算新哈希后，哈希校验通过。没有调用 Schema、执行验证或 Hub 审核。这是职责边界，并非哈希函数缺陷。

## 存储与平台

`src/gep/paths.js` 将运行资产默认放在 `<workspace>/.evolver/gep/`，可用 `GEP_ASSETS_DIR` 覆盖。`assets/gep/genes.seed.json` 是随包种子，两者不能混淆。

Hub 用接口提供跨节点资产和任务服务，网页供人操作。克隆 Evolver 不能被视为部署了完整生产 Hub。这里没有推断后台数据库、评分代码或完整服务拓扑。

## 与相邻技术的关系

| 机制 | 主要用途 | 理解边界 |
| --- | --- | --- |
| 检索 | 找相关资料 | 经验系统也需要检索，还带步骤与反馈 |
| Skill／操作说明 | 给 AI 做事方法 | 可以与 Gene 相似；结构化不自动证明更好 |
| 工具接口 | 调用外部能力 | 提供渠道，不自动产生正确经验 |
| 经验循环 | 执行后记录，影响后续决策 | 是 Evolver 着重组织的部分 |
| 模型训练 | 更新模型内部参数 | 本次实验没有进行 |

没有对照实验前，不能宣称 Gene 天然优于普通操作说明或检索系统。
