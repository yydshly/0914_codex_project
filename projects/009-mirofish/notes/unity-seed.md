# Unity Runtime Fee：截至 2023-09-22 的公开材料摘要

这是研究者整理的输入材料起点，不是完整客户样本、原始政策全文或模型运行结果。事实与角色设计应分开；此文件不包含后续取消公告。

## 一名开发者的公开反馈

2023-09-13，Garry Newman 在个人文章中反对 Unity 的新收费政策。他将费用本身与规则变更分开讨论，认为未提前充分告知和协商的变化损害了信任，并提到团队长期投入。他的意见只代表这一公开表述，不能直接外推为所有开发者的立场。

来源：https://garry.net/posts/unity-can-get-fucked

## 官方修订与沟通

2023-09-22，Unity 发布公开信道歉，承认应在公布方案前与更多开发者沟通。修订内容包括限制 Runtime Fee 的适用范围、关联未来编辑器版本，以及继续使用同版本时维持对应条款的承诺。具体门槛、计费条件与例外应以当日原文核对，不用本摘要替代完整规则。

来源：https://unity.com/blog/an-open-letter-to-our-community

## 尚缺的材料

- 不同类型开发者的独立反馈，尤其是不公开发声者。
- 合法获得的客户分层、项目阶段、商业模式和实际使用信息。
- 当时完整的适用条款与历史承诺。
- 公司的可选方案、成本约束与可兑现的保障。

不要为了凑足角色数量，假造真人证词、客户比例或经营数据。由模型补充的设定必须单列为假设。
